# Hypertension Prediction

The **Hypertension Prediction** system leverages machine learning techniques to predict the likelihood of hypertension based on various health factors. It uses a dataset containing key attributes like age, gender, BMI, and other health-related factors to classify individuals as hypertensive or not.

## Features

- **Data Preprocessing**: The dataset is cleaned, normalized, and prepared for model training.
- **Model Training**: Several machine learning models (e.g., Logistic Regression, Random Forest, etc.) are trained to predict hypertension.
- **Prediction**: The system can predict whether an individual is at risk of hypertension based on input features.
- **Evaluation**: The performance of the model is evaluated using metrics like accuracy, precision, recall, and F1-score.

## Tech Stack

- **Programming Language**: Python
- **Libraries**: 
  - `Pandas` (for data manipulation)
  - `NumPy` (for numerical computations)
  - `Scikit-learn` (for building and evaluating machine learning models)
  - `Matplotlib` and `Seaborn` (for data visualization)
- **Modeling**: Logistic Regression, Random Forest, SVM
- **Environment**: Jupyter Notebook / Python IDE
